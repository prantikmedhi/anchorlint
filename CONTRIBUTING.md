# Contributing

Read AGENTS.md and SECURITY.md. Open a focused issue or pull request with the problem, expected behavior, smallest reproduction and actual verification commands. Keep the CLI default local/read-only. Do not add fabricated benchmark numbers, SEO guarantees or generated recommendations masquerading as evidence.

A bug fix needs a failing regression test first. Provider tests use explicit test doubles, not personal keys. Run unittest, Ruff, package build, clean wheel installation and docs checks. Update examples and agent docs if the interface changes. Contributions are under the repository's MIT license.
